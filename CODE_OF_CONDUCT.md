# Code of conduct

This is a small project about careful attribution. The same care applies to how we talk to each other.

## Expected behaviour

- Discuss ideas, evidence and code rather than people.
- Assume good faith, especially when someone is reporting an attribution they believe is wrong.
- Give corrections with evidence where possible; accept that some questions have no definitive answer.
- Respect privacy. Do not publish anyone's personal data, private notes, exported library or contact details.
- Keep reports and reviews relevant to the project.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, deliberate misinformation, publishing private information without consent, or sustained disruption of issues and pull requests.

## Scope

This applies to the repository, issue tracker, pull requests, discussions and any project space where you are representing the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately through the GitHub profile associated with [LIN4CRE/Quotes](https://github.com/LIN4CRE). Do not open a public issue about a person.

Reports will be reviewed in good faith. Responses may range from a private request to stop, through moderation of a thread, to a block from the repository. The maintainer will avoid disclosing the reporter's identity where possible.

## Attribution and correction culture

Disagreement about a quotation's attribution is not a conduct problem. State the evidence, accept uncertainty, and keep the discussion about the text. Corrections are welcome; certainty is not required to ask a question.
